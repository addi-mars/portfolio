The Art of Never Dying

A treatise on victory tries to define, contain, and erase an anomaly—a small pink square known only by its gesture. Every rule it writes, the square exploits. When the square finally disappears, the rules discover it has spread into everything.

ConceptStory · Language · Motion

“You can defeat a person. You cannot defeat what they set in motion.”

The story

A visual treatise—“A Treatise on Victory”—writes rule after rule to contain one irregular square. The square slips every one. When it is finally gone, the treatise renames itself “The Art of Never Dying”: the rules learned from the anomaly.

Visual language

Three states that collide: the Manual (bone paper, ink grids, classical type, Sun Tzu in the Giles translation), the Anomaly (one pigskin square, the only warm colour) and the Voices (a field of squares that slowly learn its gesture). A red system log narrates the breakdown.

Motion principles

Containment, escalation, interruption, propagation. Every effect must have a narrative consequence: walls close, the world wraps, the table melts, the net twists, an eraser wipes the page. Humour interrupts grandeur—72 vectors converge on one potato, and he sits on it.

Techniques

One gesture as identity

He is never drawn—only recognised by motion. Hop (0–22% of a beat, ease-out), a deadpan hang with a −9° tilt (22–50%), the drop (50–60%), then a slam with squash and a five-point crown spark. Built with expressions, so any layer can perform it on cue through time-remapping.

Crowd contagion

A tiled grid of the same gesture runs through Time Displacement, driven by a quantised radial map centred on the empty cell. The gesture spreads outward like a rumour; on the final bar the delay animates to zero and everyone moves together.

Rotoscope, stepped

Stock footage (Pexels) reduced to flat silhouettes: luma threshold at 70, a two-tone tint, then stepped to 8 fps so the motion reads as hand-traced frames rather than video.

One project, many comps

Every version lives as its own folder of comps inside one master After Effects project, sharing the same precomps—the gesture, the crowd grid, the delay maps. Key beats are checked with Save Frame As, then the main comp is queued to Media Encoder so the next version can start while the last one renders.

In After EffectsComp structure · Expressions · Effects

Everything here was built by hand in one After Effects project: shape layers, precomps and expressions, with one null that turns the song into data. No plug-ins. These are the rigs that do the heavy lifting.

Comp structure

Expressions

The beat as a number

Prefix of every gesture expression

// 85 BPM → one beat = 0.70588 s
var B = 60 / 85;
var p = (time % B) / B;  // 0 → 1, every beat

Every rig starts here. p is how far we are through the current beat, so motion is written as a function of the music instead of keyframes, and it can never drift off the grid.

The gesture, with no keyframes

UNIT_gesture › Square › Position

var B = 0.70588, p = (time % B) / B, y = 0;
if (p < 0.22) {          // hop: ease-out cubic
  var q = p / 0.22;
  y = -80 * (1 - Math.pow(1 - q, 3));
} else if (p < 0.5) {    // deadpan hang
  y = -80 - 6 * Math.sin((p - 0.22) / 0.28 * Math.PI);
} else if (p < 0.6) {    // the drop
  var q = (p - 0.5) / 0.1;
  y = -80 * (1 - q * q);
}
[80, 180 + y]

Scale squashes to 88/114 on take-off and 130/74 on landing; Rotation snaps to −9° during the hang; a five-ray crown spark scales 60 → 120 and fades between 60% and 90% of the beat. Anchor at the base so the squash plants on the ground.

Fire on cue

ANOMALY precomp › Time Remap

var T = [12.40, 15.22, 18.04];  // cue times (s)
var B = 0.70588, last = -99;
for (var i = 0; i < T.length; i++)
  if (time >= T[i]) last = T[i];
var d = time - last;
(d >= 0 && d < B * 0.98) ? d : 0  // one beat, then rest

The precomp holds its rest pose on frame 0 until a cue, plays exactly one beat of the gesture, then returns to rest. Re-timing a moment means editing the array, not sliding keyframes.

Contagion

CROWD precomp › Time Displacement

CROWD

Darker blocks play sooner, so the gesture spreads outward from the empty cell like a rumour. Mosaic quantises the ramp into rings. On the last bar Max Displacement is keyed to 0 and the whole crowd moves at once.

Audio as data

Equaliser bars › Scale

// AUDIO REACT null ← Convert Audio to Keyframes
var a = comp("MAIN").layer("AUDIO REACT")
          .effect("Amp")("Slider");
var d = Math.abs(index - 32) * 0.012;  // ripple out
var v = a.valueAtTime(time - d);
[100, v * v * 70]   // squared: quiet stays flat

Amp comes from Convert Audio to Keyframes on the song. Kick comes from a duplicate audio layer through High-Low Pass (low pass around 140 Hz), converted the same way. Every reactive layer pick-whips one of those two sliders.

ReflectionWhat worked · What’s next

What worked

Defining the story before the effects. Once the anomaly had one recognisable gesture, every technique—repeaters, roto, time displacement—could serve that single idea instead of decorating it.

What I’d push next

Push the inheritance further: more variation in how the crowd re-interprets the gesture, and a longer silence before the final hop.

The Voices

Technoblade called his chat “the voices.” Here they are the only material: his face is built from ~1,300 cycling letters, the chant is made of chant, the sword is made of BLOOD and the crops are made of “potato.”

ConceptStory · Language · Motion

“He was never alone on screen. The voices were in every fight.”

The story

The chat wakes, accelerates with the music and resolves into his face. Through the drop the voices become every weapon he used—the chant, the E, the Orphan Obliterator—then fall quiet in a field of “potato” before the bass returns and they chant him back: “Technoblade joined the game.”

Visual language

Black ground, blood and gold, and letters as the only texture: Monocraft for chat, blackletter for the chant, Anton for the slams. Every image is built out of messages—portraits, a sword, crops and a 3D head are all text.

Motion principles

Density follows the music: one message a beat in the intro, eight by the drop. Words act as windows (track mattes) onto the voices, his face warps one distortion per beat, and everything collapses into a single E before the silence.

Techniques

Skin → letters

His skin’s face was sampled into a ten-colour palette map and typed as one string per row. Each row is a text layer whose Source Text expression cycles letters from TECHNOBLADE NEVER DIES BLOOD GOD POTATO at 10 fps, with one animator per palette colour whose Expression Selector switches its Fill Color on wherever the row string has that colour.

A head made of voices

The six faces of the head are separate letter mosaics folded into a cube under a 3D camera, with a solid gold crown rim. The net shows the skin faces it unfolds from.

Words made of words

Every giant word is a track matte over a wall of tiny cycling letters, so the chant is literally made of the chat. A bulge driven by the kick drum pumps the letters on every hit.

The render lesson

Thousands of per-frame text expressions made this the slowest piece in the series to render (about 30 minutes). That cost shaped the next study: The Dossier was rebuilt at 24 fps with photographed paper and stepped motion, and rendered in about 2 minutes.

Comp structure

Expressions

A chat that speeds up

CHAT › Text › Source Text

var b = (time - t0) / 0.70588;        // beats in
var S = [[1,1],[4,2],[8,4],[12,8]];    // [beat, msgs/beat]
var n = 0;
for (var i = 0; i < S.length; i++) {
  var a = S[i][0], e = i+1 < S.length ? S[i+1][0] : 1e9;
  if (b > a) n += Math.floor((Math.min(b, e) - a) * S[i][1]);
}
var L = [];
for (var k = n - 20; k < n; k++) {
  if (k < 0) { L.push(" "); continue; }
  seedRandom(k, true);           // message k never changes
  L.push("<voice_" + Math.floor(random(1000, 9999)) + "> "
         + P[Math.floor(random(P.length))]);
}
L.join("\r")

n counts how many messages have arrived, following a schedule that doubles the rate every four bars. Seeding the random with the message number means each line is stable once it appears, and the log scrolls simply because the window of the last 20 moves.

Letters that never sit still

WALL / MOSAIC row › Source Text

posterizeTime(10);                     // 10 swaps a second
seedRandom(index * 977 + Math.floor(time * 10), true);
var cs = "TECHNOBLADENEVERDIESBLOODGODPOTATO";
var s = "";
for (var i = 0; i < 64; i++)
  s += cs.charAt(Math.floor(random(cs.length)));
s

posterizeTime keeps the flicker readable instead of 30 fps noise. index in the seed gives every row its own sequence. Wall rows also scroll with a looping Position expression, alternate rows in opposite directions.

Painting with an Expression Selector

Row › Animator “c P” › Expression Selector › Amount

// Animator "c P" › Fill Color = pigskin #F2A09A
// one animator per palette colour, per row
var row = "nnPPPPPPnn";      // this row’s colour map
var v = row.charAt(textIndex - 1) == "P" ? 100 : 0;
[v, v, v]

This is how a face appears in random letters. Each row carries a string with one character per column: P for pigskin, Y for gold, n for shadow, and so on. Each animator switches its colour on only where its letter appears, so the letters keep cycling while the colours stay put.

Hitting on the kick

Word layers › Scale · Position

var k = comp("MAIN").layer("AUDIO REACT")
          .effect("Kick")("Slider");

// Scale—pump
value * (1 + k * 0.05)

// Position—NOT EVEN CLOSE shake
seedRandom(Math.floor(time * 30), true);
value + [random(-1, 1), random(-1, 1)] * k * 30

Kick is a low-passed copy of the song run through Convert Audio to Keyframes. The same slider drives the Bulge height on the BLOOD windows, the chant opacity (85 + k·15) and the sword’s scale, so everything hits together.

The corridor of voices

CORRIDOR › Camera + 90 text layers

// Camera › Position—dolly at 4,400 px/s
[960, 540, -2600 + (time - t0) * 4400]

// Camera › Point of Interest—locked ahead
transform.position + [0, 0, 1000]

// each chat layer › Opacity—fade by distance
var cz = -2600 + (time - t0) * 4400;
var d = transform.position[2] - cz;
d < 150 ? 0 : linear(d, 150, 9000, 100, 15)

Tying the point of interest to the camera’s own position stops it flipping as it passes through the layers. Each line knows how far it is from the lens, so it fades in from the dark and vanishes just before it would clip.

A head made of letters

HEAD_3D › hub null › Rotation

// six MOSAIC_face precomps, 3D, parented to a hub
// hub › Y Rotation
time * 50 + Math.sin(time * 2.2) * 14
// hub › X Rotation
Math.sin(time * 1.3) * 14 - 10

The cube is six flat precomps folded around a 3D null, with a gold crown rim on top. A steady spin plus two out-of-phase sines gives a turntable that wobbles like it is being held, not rendered.

The Dossier

The governments he kept beating opened a file on him. Photocopied, stamped, redacted and annotated in red marker—and it still can’t hold him.

ConceptStory · Language · Motion

“Case closed? lol no.”

The story

A state file on Subject 001. Incident reports, surveillance, a sketch artist and a probability chart all try to pin him down; the redacted report only leaves the chant. Field notes find him farming. The file burns, the evidence board is stamped CASE CLOSED—and red marker disagrees.

Techniques

Material library

Photographed paper instead of procedural noise: soft and hard crumples, xerox grit, kraft, ink bloom and torn grid paper (Pexels), multiplied and tinted per scene. Cheaper to render and more convincing than generated texture.

Redaction as copywriting

The report is real prose; every word is measured and either barred or circled. Only five words survive, in reading order, so the censorship itself spells the chant.

His face, from the file

The mugshot, the boiling sketch and the evidence-board figure are all built from his skin file: halftoned for the photocopy, outlined for the sketch, full colour once the file burns.

Export-friendly by design

24 fps master stepped at 12 fps, photographed textures and no per-frame text expressions. Sixty seconds that took about 30 minutes to render in study 02 rendered in about 2 minutes here, through Media Encoder.

ACT III  Posterize Time   12 fps
ACT IV—// the burn runs on full 24

// inside expressions, match the step:
posterizeTime(12);

Every layer under an adjustment layer is held for two frames, so paper moves like it was shot on a rostrum camera. Act IV is left on 24 so the burn feels real by contrast. Stepping also halves the unique frames the renderer has to draw.

Ink that boils

Sketch › Turbulent Displace › Evolution

// Turbulent Displace   Amount 12 · Size 40
posterizeTime(8);
time * 300

// the ink wash gets the same, plus
// Roughen Edges   border 10 · sharpness 1 · scale 30

Evolution jumps 8 times a second instead of sliding, which is what makes a drawing “boil” rather than wobble. The sketch outline comes from the PX_head precomp, so the suspect is always him.

The tracker that can’t keep up

Tracking box › Position · Label › Source Text

// Box › Position—always a beat behind
thisComp.layer("TARGET").transform.position
  .valueAtTime(time - 0.22)

// Label › Position—follows the box
thisComp.layer("TARGET").transform.position
  .valueAtTime(time - 0.22) + [-165, -185]

// Label › Source Text—flips every half beat
Math.floor(time * 85 / 60 * 2) % 2
  ? "TARGET LOST" : "TARGET ACQUIRED?"

Only TARGET is keyframed. The box chases where he was 0.22 s ago, so it is always slightly wrong, and the label argues with itself in time with the music.

Punch on the kick

Adjustment layer › Transform › Scale Height

posterizeTime(12);
var k = comp("MAIN").layer("AUDIO REACT")
          .effect("Kick")("Slider");
time < musicEnd ? 101 + k * 3 : 100

A 1–4% vertical squash on every kick, stepped like everything else, so the whole page jolts with the bass. It switches off when the music ends so the final page is dead still.

The report was written first as real prose, then each word was measured and either barred or circled. Only five words survive, in reading order. Revision v04b added one bar and removed another so they spell the chant exactly.

What worked

Giving him a voice on the page. The state speaks in typewriter caps and stamps; he answers in red marker—the whole joke of the piece lives in that contrast.

What I’d push next

A more physical camera—real paper movement, shadows and depth between sheets—and a longer silent beat before “lol no.”

07

Turning points

  1. A

    Story before effects

    Five versions in, the effects were wild and the piece said nothing. Stopping to write the story first—The Art of War as his playbook—gave every effect a job.

  2. B

    Designing for export

    Study 02 took about 30 minutes to render. Study 03 was planned around the renderer: 24 fps stepped on twos, photographed textures, no per-frame text expressions. It rendered in about 2 minutes, queued in Media Encoder while the next version was built.

  3. C

    Measuring motion

    Feedback was “no odd static moments.” Rather than guessing, consecutive frames were compared to find every frozen stretch, and each one was given motion in v11 and v12.
